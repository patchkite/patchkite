# Changelog

All notable changes to the Patchkite server and dashboard are documented here. This project follows [Semantic Versioning](https://semver.org/).

## 1.0.0

First public release.

- Server: apps, deployments, releases, promote, rollback, staged rollouts, mandatory and disabled releases, semver target binary versions.
- Diff updates against the last five releases, and bsdiff binary patches for large files, including patches from a store binary's built-in bundle.
- Code signing (RS256), install metrics, collaborators, access keys, and admin-managed user accounts.
- Web dashboard for managing apps, releases, metrics, users, and access keys.
- Docker images for local, single-host, and production deployments.
